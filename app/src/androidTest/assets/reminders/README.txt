Synthetic instruction corpus, not patient or real clinical audio. WAVs generated with FFmpeg flite/slt at 16 kHz mono. corpus.json records expected task counts and unresolved details for manual Gemma evaluation. These fixtures do not demonstrate noisy speech, Malayalam/Hindi, regional accents, real token announcements, medicine safety or on-phone extraction accuracy. JSON validation tests cannot measure semantic false extractions; run the model and compare every output to the corpus before claiming accuracy.
